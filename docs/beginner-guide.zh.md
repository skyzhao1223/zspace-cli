# 新手指南：让 AI 帮你整理 NAS（零代码基础）

> 不需要会编程。只要你能安装软件、会复制粘贴，就能跟着走完，全程约 15~30 分钟。
> 每一步都写了「✅ 成功是什么样」和「❌ 失败怎么办」。

## 这是干什么的？

你的 NAS 里是不是堆了好几年的东西：手机自动备份的照片、下载完就忘的文件、
八个「最终版」的工作文档……

这个项目会给你的 **AI 助手**（比如 Claude Code）装上一套「**整理说明书**」，
然后你只要对它说一句：

> 「帮我把 NAS 里的照片按日期整理好」

AI 就会先扫描、列一份计划给你过目，**你点头它才动手**。

## 先吃三颗定心丸

1. **扫描只读**：所有整理的第一步都是"只看不动"，先出一份报告
2. **确认才动手**：AI 必须先给你看「旧名字 → 新名字 / 移到哪」的清单，你说"确认"它才执行
3. **删除先隔离**：建议删除的文件会先挪进一个隔离文件夹，你看过没问题才真删

项目是开源的（MIT 协议），所有代码都公开在 [GitHub](https://github.com/skyzhao1223/zspace-cli)，不碰你的账号密码（极空间走的是你本机已登录的桌面客户端）。

## 你需要准备什么？

- [ ] 一台 NAS（极空间 / 群晖 / 威联通 / 绿联……什么牌子都行）
- [ ] 一台电脑（本指南以 **Mac** 为例；Windows 见文中提示）
- [ ] 一个 **AI 助手**，任选其一装好：Claude Code（推荐）、Cursor、Trae 等
      ——就是那种"能聊天、又能帮你操作电脑"的工具
- [ ] 15~30 分钟

## 只解释 6 个名词

| 名词 | 大白话 |
|------|--------|
| NAS | 家里/公司那台存东西的"网络硬盘盒子" |
| 终端 | Mac 上一个打字执行命令的窗口（按 ⌘+空格 搜"终端"或"Terminal"） |
| 命令 | 复制粘贴到终端里、按回车执行的一行字 |
| 挂载 | 把 NAS 上的文件夹变成你电脑里的一个"本地磁盘"，之后就像操作本地文件一样 |
| AI 助手（Agent） | 能直接操作你电脑的 AI，比如 Claude Code、Cursor |
| skill | 给 AI 助手看的"整理说明书"，本项目提供 9 本 |

## 第 1 步：检查电脑有没有 Python

打开「终端」，粘贴这行，按回车：

```bash
python3 --version
```

- ✅ 显示 `Python 3.9.6` 或更高 → 下一步
- ❌ 提示 `command not found` → 去 https://www.python.org/downloads/ 下载安装，装完重开终端再试

## 第 2 步：安装本项目

粘贴到终端，按回车：

```bash
pip3 install zspace-cli
```

- ✅ 最后出现 `Successfully installed zspace-cli-...` → 成功
- ❌ 提示 `command not found: pip3` → 改用 `python3 -m pip install zspace-cli`

## 第 3 步（极空间用户）：验证连接

前提：Mac 上的**极空间桌面客户端已登录、正在运行**（就是你平时看文件那个 App）。

```bash
zs check
```

- ✅ 显示连接成功 → 跳到第 5 步（你不需要挂载）
- ❌ 不通 → 确认极空间 App 是打开且登录状态，再跑一次

> Windows 用户：命令相同；若提示找不到 `zs`，重开一个终端窗口再试。

## 第 3 步（群晖/威联通/绿联等用户）：挂载 NAS 文件夹

**Mac**：

1. 访达（Finder）菜单栏点「前往」→「连接服务器…」（快捷键 ⌘K）
2. 输入 `smb://你的NAS的IP`，比如 `smb://192.168.1.100`，点「连接」
3. 输入 NAS 的账号密码，勾选要挂载的文件夹（比如「photo」）
4. 成功后访达侧边栏「位置」下会多出一个磁盘，它的完整路径是 `/Volumes/photo`

**Windows**：打开「此电脑」→ 右键「映射网络驱动器」→ 输入 `\\你的NAS的IP\photo`
→ 完成后它就是一个盘符（比如 `Z:`），后文把 `/Volumes/photo` 换成 `Z:\photo` 即可。

> 不知道 NAS 的 IP？登录 NAS 的网页管理后台能看到，或在路由器管理页里找。

## 第 4 步：把「整理说明书」交给 AI 助手

先建一个文件夹当作"整理工作区"，再把 skill 装进去：

```bash
mkdir -p ~/my-nas
zs skill ~/my-nas/skills/
```

- ✅ 显示 `OK 已复制 9 个 skill` → 成功
- 只想装几本？`zs skill --list` 看清单，`zs skill ~/my-nas/skills/ --only nas-report,photo-organizer` 选装

然后打开你的 AI 助手，**把工作区文件夹作为项目打开**：

- Claude Code：终端里 `cd ~/my-nas`，然后输入 `claude` 回车
- Cursor / Trae：菜单 File → Open Folder，选 `my-nas` 文件夹

## 第 5 步：开口说第一句话

对着 AI 直接说中文就行。例子：

| 你说 | AI 会做什么 |
|------|------------|
| 「给我出个 NAS 存储报告」 | 全盘体检：空间被什么占了、最乱的是哪、建议先整理什么 |
| 「帮我整理 /Volumes/photo，按日期归档」 | 扫照片 → 给你归档计划 → 你确认后移动 |
| 「找找重复文件，看能腾多少空间」 | 内容级查重（零误报），列出可删清单让你确认 |
| 「清理一下下载目录」 | 分诊：安装包/种子/半截下载/该归档的影视 |
| 「我的备份还新鲜吗」 | 审计备份：过期的、缺的、能轮转删的 |
| （极空间）「列出 NAS /sata11/my/data 里的文件」 | 直接浏览，不用挂载 |

**建议第一句就说「给我出个存储报告」**——它会告诉你该从哪开始。

## 不想装 AI 助手？只想看报告也行

报告是给人看的中文，手动跑一条命令就出：

```bash
python3 ~/my-nas/skills/nas-report/nas_report.py report --root /Volumes/photo
```

把输出截图发给任何聊天 AI（豆包 / Kimi / DeepSeek…）问"我该怎么整理"，
也能拿到建议——只是后续动手要你自己来。

## 出问题了？（FAQ）

| 现象 | 怎么办 |
|------|--------|
| `command not found: zs` | 关掉终端重开一个；还不行就确认第 2 步显示过 Successfully installed |
| `command not found: python3` / `pip3` | 回第 1 步装 Python |
| `zs check` 不通 | 极空间客户端必须**开着且已登录**（光装了不行） |
| 挂载失败 / 连不上服务器 | 核对 IP、账号密码；确认 NAS 后台开了 SMB 服务 |
| AI 说找不到 skill | 确认 AI 助手打开的项目里有 `skills` 文件夹（第 4 步装的位置），重新打开项目 |
| 扫描很慢 | NAS 文件太多属正常；让 AI 加 `--sample 2000` 先摸底 |
| 还是不放心 | 直接对 AI 说「只出计划，先不要执行」 |
